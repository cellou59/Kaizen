# API Docs

## Authentication

- Supabase Auth (JWT), email + password

## Authorization

- Supabase RLS (Row Level Security) per user

## Session

- Supabase session cookies managed by `@supabase/ssr`

## Format

- Server Actions (not REST/GraphQL)
- No REST API endpoints
- No versioning
